Module 1: First-Order Time Response

A thermometer-type sensor obeys τ ẏ + y = K x, with transfer function G(s) = K / (τs + 1). Change K, τ, the input size and the input type, and watch how the sensor lags behind the ideal output K·x.

Error fraction (logarithmic scale)

The fraction of the change still to go is E(t) = e−t/τ. On a log axis it is a straight line, because ln E = −t/τ, so the slope is −1/τ.

Module 2: First-Order Frequency Response

For a sine input the steady-state output is a sine of the same frequency, scaled by M = 1/√(1 + (ωτ)²) and delayed by a phase φ = −tan⁻¹(ωτ). The dynamic error is δ = M − 1.

Amplitude ratio and phase lag

Bode plot

At the cutoff ω = 1/τ the gain is 0.707 (−3 dB) and the phase is −45°. Above it the gain falls at −20 dB/decade.

Dynamic error calculator

How slow can the sensor be? Require M ≥ 1 − ε up to the highest signal frequency: τmax = √(1/(1−ε)² − 1) / (2π f).
