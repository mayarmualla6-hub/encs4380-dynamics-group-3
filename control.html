P2: A Slow Sensor in the Loop

The controller never sees the true output y. It sees the sensor reading ym, where τs ẏm + ym = y. A slow sensor reports old news, so the controller keeps pushing after the real output has already arrived. The controller only controls what the sensor says.

P3: Digital PID

On an Arduino the controller only runs once every Ts seconds and holds u constant in between: u[k] = Kp e[k] + Ki Ts Σj=0..k e[j] + Kd (e[k] − e[k−1]) / Ts. Start with a small Ts and raise it until the response breaks.
